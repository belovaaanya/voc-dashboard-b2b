# Блоки метрик

Строка метрик дашборда: большая карточка VOC канала, три сегментные карточки и
вторая строка счётчиков. Первые блоки, вставшие в
[контракт блока](ui-shell.md#контракт-блока).

Связанные документы: [calc-core](calc-core.md) (откуда берутся числа),
[design-spec §3](design-spec.md#3-строка-метрик-1400--201) (замеры),
[design-validation](design-validation.md) (`V-xx`), [decisions](decisions.md) (`D-xx`).

| Модуль | Блок |
| --- | --- |
| [`blocks/voc-channel.js`](../site/js/blocks/voc-channel.js) | большая карточка VOC текущего среза |
| [`blocks/voc-segment.js`](../site/js/blocks/voc-segment.js) | сегментная карточка, она же переключатель фильтра |
| [`blocks/tally.js`](../site/js/blocks/tally.js) | вторая строка: `Оценок`, `Низких оценок`, `Доля 5★` |
| [`blocks/metric-card.js`](../site/js/blocks/metric-card.js) | общие части: дельта, точка тренда, бейдж, коридор, объём, пометка выборки |

`metric-card.js` — только представление. Ни одного расчёта: значения приходят
из ядра, строки — из `format.js`.

## 1. Композиция

Состав и порядок элементов взяты из wireframe `3204:2723`; геометрия — наша
(`V-01`…`V-03`), значения из макета не переносятся.

**Большая карточка** (`MetricCell/Big`, §3.1). Заголовок и бейдж плана на одной
строке, под бейджем справа — дельта, ниже крупное значение слева и коридор с
объёмом справа от него. Занимает обе строки метрик, как в расширенном варианте
макета, поэтому содержимое центрируется по высоте.

**Сегментная карточка** (`MetricCell/Small`, §3.2). Заголовок и точка тренда в
шапке, ниже две колонки: значение слева внизу, дельта и объём — справа сверху и
снизу. Планового бейджа здесь нет: в макете коридор показан только у карточки
канала. Пометка выборки идёт под обеими колонками — в узкой колонке она
переплетается с объёмом.

**Вторая строка** (расширенный вариант, `V-10a`, `V-25`). Заголовок и точка
тренда в шапке, крупное значение и мелкая дельта рядом с ним. Три карточки
стоят в тех же колонках, что VOC-карточки над ними.

Значение тянется за шириной карточки. Строка метрик в макете — `1400`, а
страница живёт от `--content-min: 1200`, поэтому фиксированный кегль из
`design-spec` на узком конце наезжает на коридор и объём. Верхняя граница
`clamp` — размер из макета; там, где рядом уже не помещается, подписи уходят
под значение, а не поверх него.

Заголовки ставят сами блоки, а не каркас: заголовок обязан называть тот срез,
который показан числом. При фильтре по одному сегменту заголовок большой
карточки становится `VOC <канал>, <сегмент>`, при остальных фильтрах —
`VOC <канал>, срез по фильтрам`. «VOC канала» над значением одного сегмента —
то же противоречие интерфейса самому себе, от которого защищает `D-22`.

## 2. Откуда берутся числа

| Что на экране | Чем считается |
| --- | --- |
| Значение | `metrics.voc` от среза карточки |
| Дельта VOC | `metrics.vocDelta(срез, срез предыдущего периода)` |
| Дельта счётчика и доли | `metrics.deltaOf(текущее, предыдущее)` |
| Направление тренда | `metrics.trendOf(показанная дельта)` — по знаку, не отдельным полем (`V-15`) |
| Бейдж плана | `plan.planStatus` по округлённому значению (`D-22`) |
| Коридор | `plan.planForSlice` (`D-42`) |
| Объём, низкие, доля 5★ | `metrics.summarize` |
| Пометка выборки | `sufficiency.sampleSufficiency` (`D-25`) |

Предыдущий период — `period.previousPeriod` от текущего (`D-23`, `D-24`).
Пустой предыдущий срез даёт `null`, и дельта не рисуется вовсе: «сравнивать не
с чем» и «не изменилось» — разные ответы. На апрельском срезе сэмпла дельт нет
именно поэтому — марта в выгрузке нет. Для счётчиков это правило приходится
задавать явно: `count` пустого среза — честный `0`, и без проверки «+10 459»
читалось бы как рост с нуля.

**Точность у каждого показателя своя, и направление обязано ей следовать.**
VOC и его дельта — два знака, счётчики — целые, доли — один знак (`D-40`).
Пару «округление + формат» держит `DELTA_SHAPES` в `metric-card.js`, и стрелка
выводится из того же округлённого числа, которое напечатано рядом: иначе
`+0,04` п. п. дало бы стрелку роста рядом с подписью `+0,0` — то же
противоречие, от которого защищает `D-22`.

## 3. Плановый коридор

Коридор показывает только большая карточка — так в макете. Он описывает пару
(канал, сегмент) и период; правила выбора записи — `D-42`:

- запись выбранного сегмента, если он ровно один, иначе запись канала
  (`segment: null`);
- фильтр по любому другому измерению — коридора нет: канальная цель ничего не
  говорит о срезе «АБМ + Выписка»;
- запись обязана покрывать выбранный период целиком.

Записи под срез нет — ни бейджа, ни строки коридора, остальная карточка
работает (`D-04`). На сэмпле это видно на канале `НИБ` за апрель.

Сравнение идёт по значению, **округлённому до отображаемых двух знаков**,
границы включительно (`D-22`). Границы округляются тем же правилом: подпись
коридора показывает их с двумя знаками, и сравнение с неокруглённой границей
противоречило бы собственной подписи.

## 4. Кликабельность

Клик по сегментной карточке ставит фильтр по сегменту в URL (`D-31`), повторный
клик снимает. Остальные блоки перестраиваются, потому что перестраивается весь
контекст.

Сегментные карточки при этом считают свой срез **без** фильтра по сегменту
(`D-43`): иначе после первого клика три карточки из четырёх показывают «нет
данных» и выбрать другой сегмент нечем.

Доступность:

- переключатель — настоящий `<button>` внутри карточки, поэтому попадает в обход
  по `Tab` и срабатывает по `Enter` / `Space` без своей обработки клавиш;
- состояние объявлено через `aria-pressed`, а имя — через `aria-label`
  («Отфильтровать дашборд по сегменту» / «Снять фильтр по сегменту»);
- в макете кликабельность ничем не обозначена (`V-26`), поэтому состояния
  заданы на нашей стороне: указатель и подсветка рамки при наведении, кольцо
  фокуса от каркаса, а применённый фильтр удваивает рамку внутренней тенью и
  опускает фон. Форма и светлота различают выбранную карточку в grayscale, то
  есть цвет здесь не единственный носитель (`D-26`).

## 5. Недостаточная выборка

Пометка появляется, когда полуширина 95 % доверительного интервала VOC
превышает порог (`D-25`), и несёт саму величину: «Мало оценок: ±0,25 к VOC».
«Мало» без величины не подсказывает, насколько не доверять числу. Одна оценка —
интервал не определён, и это сказано словами.

На сэмпле пометка видна на сегменте `КИБ`: он специально мелкий.

## 6. Служебные состояния

`загрузка` и `ошибка` каркас держит на всех блоках сразу. Пустоту каждая
карточка объявляет по **своему** подсрезу: сегмент бывает пуст там, где канал
полон (`D-34`). Пометка в шапке — бейдж или точка тренда — переживает смену
состояния, поэтому каждая отрисовка либо ставит её, либо гасит.
