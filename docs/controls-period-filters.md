# Контролы периода и фильтров

Слайс закрывает `P0 №1`, `P0 №2` и `P1 №14`: global period становится главным
интерактивным контролом шапки, а поддержанные измерения получают единый
multi-select. Макет задаёт закрытую композицию; открытые состояния зафиксированы
нашей стороной в `V-27`.

## Период

Контрол показывает effective global period, по которому посчитан весь дашборд
(`V-11`). Он раскрывает пять быстрых preset:

- `Месяц`;
- `Полгода`;
- `Год`;
- `365 дней`;
- `5 лет`.

Все preset заканчиваются на `manifest.period.to`, а не на системной дате. Так
результат воспроизводим для одной и той же выгрузки. Custom range задаётся двумя
нативными `date input`. Неполный, невалидный или вывернутый диапазон показывает
inline ошибку и не меняет URL.

## Фильтры

Шапка выводит только измерения `segment`, `trigger`, `cp`, `product`, `domain`.
`Роли` и `ФО` отсутствуют (`D-13`), `trigger` подписан как `Триггеры` (`D-14`,
`V-21`). Значения берутся из загруженных фактов и справочника; неизвестная
подпись падает обратно на код (`D-02`).

Выбор внутри popover сначала меняет draft. `Применить` записывает все выбранные
значения измерения в URL, `Сбросить` удаляет только это измерение. Несколько
значений образуют OR внутри измерения; разные измерения пересекаются как AND
(`D-15`).

## URL и навигация

URL остаётся единственным источником состояния (`D-31`). Изменение периода или
фильтра вызывает общий `setState`, поэтому все блоки перерисовываются одним
срезом. Back / Forward восстанавливают канал, период и наборы фильтров. Клик по
сегментной карточке использует тот же `segment`, что и контрол шапки.
Параметр `preset` сохраняется вместе с `from` / `to`, чтобы Reload не превращал
календарный период в `custom` и не менял previous period (`D-23`, `D-24`).

## Global и local period

`context.period` и `context.previousPeriod` описывают global period. Единая
функция `context.select(overrides)` возвращает:

```js
{ rows, previous, period, previousPeriod }
```

Вызов без границ использует global period. Пара `from` / `to` создаёт local
period только для результата `select`, не меняя URL и global period. Передача
одной границы запрещена. Вызов без overrides после local выбора снова даёт
global period. Расчёт среза живёт в `selection.js`, блоки его не дублируют.

## Accessibility и поведение

- триггеры имеют `aria-expanded` и связь с панелью через `aria-controls`;
- popover имеет роль `dialog` и доступное имя;
- значения фильтра — нативные checkbox, даты — нативные `date input`;
- `Escape` закрывает открытый popover и возвращает фокус на триггер;
- клик вне панели закрывает её без изменения draft;
- применённое состояние различимо текстом и подчёркиванием, не только цветом
  (`D-26`).

## Проверка

Unit-тесты покрывают границы preset, custom validation, immutable multi-select,
round-trip URL и контракт global/local `select`. Contract-тест проверяет
структуру accessibility и anchored popover. В браузере проверяются preset,
custom range, multi-select, reset одного измерения, Back / Forward, `Escape`,
пустой срез и ширина `1200px`. Guard запускается на корректном коде и на
намеренно сломанной копии, которую обязан отклонить.
