# Блок «Главный вывод»

Карточка кратко называет факторы, которые сильнее всего поддерживают и снижают
VOC текущего среза. Композиция следует Figma node `3204:2849`: заголовок с
AI-marker и две строки по `32 px` с акцентной иконкой и текстом.

## Расчёт

`buildConclusion` использует то же `decomposeVocChange`, что и рейтинг
антидрайверов. Из полного разложения выбираются до двух сильнейших положительных
и отрицательных вкладов по измерению `Триггеры`. Поэтому вывод не может назвать
фактор драйвером роста, если тот же расчёт относит его к снижению (`V-16`).

Методика вклада `D-10` остаётся требующей подписи аналитики. До её пересмотра
она сосредоточена в одном core-модуле, а карточка только формулирует результат.
Значения и подписи берутся из `context.slice`, `context.previousSlice` и
справочника; строки из Figma не переносятся как данные.

## Композиция и состояния

Сначала показывается positive signal, затем negative signal. Если одного из
направлений в разложении нет, строка не придумывается. Нулевое изменение
показывается нейтральной строкой. Точный вклад каждого названного фактора
доступен в `aria-label` и нативной подсказке.

Фон иконки использует `12%` accent соответствующего направления. Стрелка и
названия факторов окрашены ярким accent, остальная формулировка остаётся белой.
Figma-guard проверен и на заведомо неверном фоне `100%`.

Формулировка помечена «Сделано с AI», потому что marker относится к
сгенерированному тексту, а не к посчитанным цифрам (`D-33`). Строки доступны
по `Tab` и имеют hover/focus-состояния. Пустой current slice использует общий
`EMPTY`, отсутствие сравнения называется явно.

После добавления распределения карточка имеет компактную высоту: вместе с ним
`rail-top` выравнивается с двухстрочной сеткой метрик (`V-31`). Внутренняя
геометрия строк и иконок остаётся Figma-композицией.
