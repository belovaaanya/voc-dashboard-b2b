## Страница, а не артборд

Дашборд — обычная веб-страница с нормальным скроллом документа, а не экран
фиксированной высоты. Из макета берётся **горизонтальная** структура:
контентная колонка `1400`, деление на колонки, порядок блоков. Высота артборда
`1342` — следствие содержимого макета, а не ограничение: блоки идут потоком и
растут по данным.

Отсюда следствие для вложенных скроллов. Горизонтальный скролл внутри тепловой
карты оправдан — колонок по времени сколько угодно (при этом появляется он
только когда колонки не влезают, `V-19`). Вертикальный скролл внутри списка
событий — нет: растёт страница, а не область внутри карточки.

| Параметр | Значение |

| Ширина артборда | `1600` |

| Высота артборда | `1342` (контент заканчивается на `1363` от верха фрейма) |

Три строки контента:

| Строка | Y (абс.) | Высота |
| --- | --- | --- |
| Шапка: канал + фильтры | `88` | `40` |
| Ключевые метрики | `140` | `201` |
| Основная область | `353` | `649` |

### Горизонтальное деление

Строка метрик — `356 + 16 + 664 + 16 + 338 = 1390`
Основная область — `1037 + 12 + 346 = 1395`

Ни одна из строк не даёт `1400`, и правые края строк не совпадают между собой
(см. [design-validation](design-validation.md), V-01). Целевая сетка задаётся
при реализации, а не копируется из макета.

## 5. Палитра

Figma-переменные к макету не привязаны (`get_variable_defs` → `{}`), то есть
слоя токенов в файле нет — он проектируется на нашей стороне. Значения ниже
сняты из PNG: для плоских заливок точные, для сглаженных краёв
приблизительные.

| Роль | HEX | Где |
| --- | --- | --- |
| Фон страницы | `#0B0B0D` | подложка (≈47 % площади) |
| Поверхность карточки | `#111214` | основные карточки |
| Поверхность вложенная | `#0D0D0F` | панели выводов, внутренние блоки |
| Акцент положительный | `#2DDA93` | линия графика, дельты роста, иконки |
| Акцент положительный, заливка | `#29C083` | бейдж `В плане` |
| Акцент отрицательный | `#FF376B` | линия падения, теги аварий, дельты |
| Заливка heatmap «хорошо» | `#13372A` → `#164C37` | тёмная часть шкалы |
| Заливка heatmap «плохо» | `#270B16` → `#2F0A19` | тёмная часть шкалы |
| Текст основной | `#FFFFFF`, `#E1E1E1` | значения, заголовки |
| Текст вторичный | `#C3C3C3` | подписи в ячейках |
| Текст третичный | `#A4A4A5` | оси, служебные подписи |

Насыщенные пиксели занимают ≈3 % площади: цвет работает как акцент на
почти чёрном фоне, а не как фон блоков.

### Типографика

Гарнитура из макета не извлечена — в файле нет привязанных text styles;
согласовать отдельно. Известны размеры контейнеров: значение большой карточки
занимает бокс `108`, малой — `48`, заголовки блоков — `20`, служебные подписи
осей — `11…12`. Начертание числовых значений — светлое.
