# Блок «Динамика VOC»

Интерактивный график для `P0 №3–4`: текущий VOC, плановый коридор, предыдущий
аналогичный период и количество оценок. Композиция сверена с Figma node
`3204:2865`; расхождения исходника учтены по `V-05`, `V-06`, `V-11`, `V-12`
и `V-28`.

## Данные и расчёт

- источник — `context.slice`, `context.previousSlice`, `context.period` и
  `context.previousPeriod` из [контракта блока](ui-shell.md#контракт-блока);
- `timeseries.js` собирает включительные интервалы `day`, `week`, `month` и
  `quarter`; пустой интервал остаётся разрывом, а не превращается в нулевой VOC;
- VOC каждого интервала считается по оценкам через `metrics.voc` (`D-07`), а не
  как среднее уже посчитанных дневных VOC;
- текущая и предыдущая линии используют одну шкалу Y; плановый коридор
  включается только когда `planForSlice` возвращает применимую запись (`D-04`,
  `D-42`);
- сравнение и границы плана показываются с отображаемой точностью `D-21`, а
  попадание на обе границы считается планом (`D-22`).

Автоматический масштаб выбирается по длине global period. Пользователь может
переключить его табами `Дни`, `Недели`, `Месяцы`, `Кварталы`; это меняет только
агрегацию графика и не меняет период или URL.

## Отрисовка

График строится собственным SVG без chart-библиотеки. Линия разбивается на
участки clip-масками: выше коридора — зелёная, в коридоре — нейтральная, ниже —
малиновая. Область под линией повторяет положительный и отрицательный акцент.
Plot обрезан внутри своих координат (`V-05`), подписи X строятся из данных
(`V-12`), подписи точек принадлежат renderer (`V-06`).

Пунктир показывает предыдущий аналогичный период. Полупрозрачные столбцы
показывают относительное число оценок в интервалах, а pill `Оценки: N` содержит
общий объём среза и включает или выключает слой. Этот слой добавлен поверх
композиции Figma по `V-28`, потому что без него не выполняется `P0 №4`.

## Интерактивность и состояния

- hover, click и keyboard focus точки открывают tooltip с интервалом, VOC и
  числом оценок;
- кнопка разворачивания открывает карточку поверх страницы и возвращает её в
  сетку;
- смена global period, канала или фильтра перестраивает обе линии, объём и
  применимость плана; локальная подпись периода всегда равна effective period
  графика (`V-11`);
- при пустом `context.slice` блок использует штатное состояние `EMPTY`.
