# Блок «Распределение оценок»

Компактная диаграмма показывает состав текущего среза по оценкам `1…5`
(`P0 №8`). Она стоит второй карточкой в верхнем правом rail: требования
разрешают отдельный верхний виджет, а в Figma готового компонента нет (`V-31`).

## Расчёт

Грань расчёта — одна оценка (`D-07`). `markDistribution` возвращает все пять
градаций, их количество и точную долю. `distributionForDisplay` передаёт доли
в `roundShares`: показан один знак после запятой, а сумма целых десятых всегда
равна `100,0 %` методом наибольших остатков (`D-40`). DOM-блок не считает
доли самостоятельно. При равных остатках tie-break минимизирует расхождение
восстановленного VOC с точным значением (`V-22`).

Проценты из спецификации не переносятся: они противоречат VOC той же карточки
(`V-22`). Значения всегда строятся из `context.slice`, поэтому изменение
канала, периода или любого фильтра одновременно меняет общий объём, доли и
ширину полос.

## Композиция и состояния

В заголовке показано число оценок. Каждая строка содержит оценку, полосу и
долю; точное количество доступно в `aria-label` и нативной подсказке. Низкие
оценки используют negative accent, высокие — positive, а подписи сохраняют
смысл без цвета (`D-26`). Строки доступны по `Tab` и имеют hover/focus-
состояния.

Пустой срез использует общее состояние `EMPTY`. Отдельного клика-фильтра по
оценке нет: такого измерения нет в согласованном наборе контролов, а `P0 №8`
требует только пересчёт от global filters.

## Проверка

- расчёт и округление: `test/distribution.test.js`, `test/round.test.js`;
- контракт renderer и состояния: `test/distribution-contract.test.js`;
- данные сэмпла: показанные доли дают `100,0 %` и воспроизводят VOC (`V-22`);
- композиция: `rail-top` выравнивается с двумя строками метрик, новое
  расхождение источника зафиксировано как `V-31`.
