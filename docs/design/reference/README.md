## Чего здесь нет

На доске есть мудборд со скриншотами сторонних продуктов (кошельки, трекеры,
аналитические панели). Это визуальные референсы, а не требования, и в
публичный репозиторий чужие продуктовые скриншоты не выкладываются — смотреть
их нужно в Figma.
