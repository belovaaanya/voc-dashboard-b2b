# Блоки «Прямая речь»

Два связанных блока из расширенного Figma-варианта: пять карточек проблем и
таблица клиентских комментариев с поиском. Карточки стоят после
антидрайверов, таблица занимает полную ширину страницы.

Источники дизайна — Figma nodes `3030:3269` и `3030:3298`; offline-fallback —
[`variant-voc-2-0.png`](design/reference/variant-voc-2-0.png) (`D-19`).

## Данные и загрузка

`ratings` остаётся источником периода, фильтров, оценки и разметки проблемы.
`verbatim.items` подключается к выбранному срезу только по `voc_ccode` и
загружается один раз при первой отрисовке текстового блока. Пока запрос идёт,
оба блока показывают `LOADING`; ошибка текста не скрывает остальные метрики.

`OSLK_EXPERTISE_NAME` не выводится (`D-05`). Карточка выбирает дословный
`CLIENT_COMMENT`: для «Частотных» — из самой низкой оценки проблемы, для
«Новых» — из последней даты с приоритетом низкой оценки. Полный текст доступен
в tooltip, визуально цитата ограничена двумя строками как в Figma.

## Карточки проблем

Группа — `problem`; цвет рамки и значение «Влияние на VOC» используют тот же
`decomposeVocChange`, что антидрайверы (`D-10`). Доля считается от всех оценок
текущего среза, sparkline показывает дневную долю проблемы.

- `Частотные` — доля по убыванию;
- `Новые` — дата последнего упоминания по убыванию, затем доля (`D-44`).

Определения «новизны» в требованиях нет. Трактовка как рост доли была
проверена на штатной синтетике и дала `0` карточек; positive control на
«Частотных» при том же aggregation key (`problem`) вернул непустой список и
конкретную строку «Платёж висит в обработке». Поэтому пустое правило заменено
на проверяемую свежесть упоминания и вынесено на пересмотр.

Композиция: пять равных карточек, минимальная высота `141 px`, padding `8 px`,
sparkline `91 × 32`. Табы — настоящие кнопки с `role=tab`, карточки доступны
по `Tab` и имеют hover/focus-состояния. Marker «Сделано с AI» сохраняет
композицию и смысл формулировки топа проблем (`D-33`).

## Таблица детализации

Колонки строго по `D-17`: `Дата`, `Канал`, `Сегмент`, `Триггер`, `Категория`,
`Оценка`, `Комментарий`. `ФО`, `Платформа`, `X-pin`, `U-pin` и `УИУКО` не
показываются, потому что источника или подтверждённой природы у них нет
(`V-23`). Несколько триггеров одной оценки остаются одной строкой и
перечисляются через `·`.

Поиск регистронезависимо проверяет все видимые поля по полной выборке. DOM
показывает результаты порциями по `20`, кнопка «Показать ещё» раскрывает
следующую порцию; это не меняет число найденных строк. Вертикального scroll
внутри карточки нет — растёт документ, как требует общий shell.
