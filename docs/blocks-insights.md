# Блок «Инсайты»

Блок заменяет нарисованный в Figma календарь событий простым, проверяемым
объяснением изменений VOC (`P1 №10`, `V-30`). Внешних источников релизов,
сбоев и CX-событий в выгрузке нет, поэтому карточки строятся только из оценок
выбранного среза и не приписывают изменению выдуманную внешнюю причину.

## Расчёт

`buildInsights` сопоставляет каждый день current period с днём того же номера
в effective previous period (`D-23`, `D-24`). День без оценок в одной из пар
пропускается. Изменение, которое после округления равно нулю, также не становится
событием: знак и показанное число не должны противоречить друг другу (`D-21`).

Для каждой пары `decomposeVocChange` раскладывает `ΔVOC` по проблемам. Причиной
падения становится самый отрицательный вклад, причиной роста — самый
положительный. Пустая разметка остаётся честной группой «Без разметки»
(`D-11`), а не заменяется догадкой. Методика вклада `D-10` по-прежнему ждёт
подписи аналитики.

Список сортируется по модулю изменения или по хронологии, новые даты идут
первыми. Любое изменение канала, периода или фильтра создаёт новый `context`,
поэтому список и причины пересчитываются из `context.slice` (`P1 №11`).

## Связка блоков

Выбранная дата хранится в query-параметре `focus` (`D-31`). Клик по карточке
инсайта или точке текущей линии графика ставит дату; повторный клик снимает её.
Точка и карточка объявляют состояние через `aria-pressed`, точки графика также
активируются `Enter` и `Space`.

При выбранной дате «Антидрайверы» получают current day через
`context.select({ from: focus, to: focus })`, а прошлую дату — по тому же
порядковому номеру в effective previous period. Global period в шапке и на
графике не меняется, а рейтинг сравнивает ту же пару дней, что и инсайт.
В заголовке локального блока видна дата и кнопка сброса.
`focus` вне global period удаляется при разрешении состояния.

Аномалия при появлении отдельного правила будет ещё одним `kind` в этом же
списке, а не отдельной карточкой (`D-16`).

## Композиция и состояния

Композиция следует Figma node `3204:3049`: заголовок с пометкой «Сделано с
AI», компактный вертикальный список, цветная точка, дата, тип, дельта, VOC и
причина. Внутреннего вертикального scrollbar нет — растёт страница. Показывается
до десяти наиболее влиятельных строк, чтобы заполнить правый рейл рядом с
графиком и антидрайверами.

Пустой global slice использует общее состояние `EMPTY`. Если оценки есть, но
нет ни одной сопоставимой ненулевой пары, блок прямо сообщает «Нет сопоставимых
изменений» и не рисует событие с нулём.
