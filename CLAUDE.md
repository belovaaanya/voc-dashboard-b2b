## Макет — источник композиции, не значений

Из макета берём состав блоков и визуальный язык. Сетку, отступы и **все
числа** — нет: геометрия местами не сходится, данные противоречат сами себе.

Это обычная скроллящаяся страница, а не экран фиксированной высоты: макет
задаёт горизонтальную структуру (колонка `1400`, деление на колонки, порядок
блоков), высота артборда ограничением не является.
Разобрано в `design-validation.md` под `V-xx` — ссылаться на этот ID в PR и
ревью. Новое расхождение — дописать туда с новым ID, а не «исправить по вкусу».

## Стек

Без framework и без bundler: ES-модули, CSS custom properties, данные через
`fetch` JSON, график — свой SVG. Chart-библиотеку не подключать — линия,
меняющая цвет при переходе через плановый коридор, дешевле рисуется, чем
перекрашивается. Обоснование и условия пересмотра — [README](README.md#стек).

Публикуется содержимое `site/` при push в `main`.

## Данные

- `data/*.xlsx` — source of truth, правится руками; схему листов менять только вместе с `docs/data-model.md`.
- `site/data/*.json` — артефакт сборки: не в git, руками не править.
- Показатели считаются из дневных фактов, а не берутся предагрегированными — иначе клик по карточке не сможет перестроить дашборд.
- Грань факта — **одна оценка** (`MARK1_VALUE`); VOC за период считается по оценкам, а не как среднее дневных VOC.
- `OPERATION_NAME` многозначный (`;`), а «Продукты» и `КП` получаются из него через справочник — суммы по этим разрезам превышают число оценок; дедупликация по `VOC_CCODE` обязательна.
- Репозиторий **публичный**: в `data/` только синтетика. Реальные выгрузки и дословные комментарии клиентов не коммитить — файл в истории git публичного репозитория необратим.

## Figma MCP

- Read-инструменты требуют **edit-доступа**: при view всё падает с `don't have edit access`.
- Перед `get_design_context` — skill `figma-design-to-code`.
- Запрашивать узел блока, не весь артборд `3204:2682` — ответ не влезает.
- Ссылки на ассеты MCP живут ~неделю, не коммитить; референс лежит в `docs/design/reference/`.

## Git

Identity задана **локально в репозитории** (`Anna Belova`,
`commit.gpgsign=false` — GPG-ключа для неё на машине нет). Это намеренно, чтобы
не менять глобальный конфиг машины: не «исправлять» и не переносить в `--global`.

## Правила

- **В конце каждого слайса** — гейт из [docs/slice-gate.md](docs/slice-gate.md): независимый code review **и** сверка дизайна. Не один раз перед PR.
- [PROGRESS.md](PROGRESS.md) — отмечать пункт после проверки результата; частично сделанный остаётся открытым.
- Документация на русском, технические термины латиницей: `deploy`, `build`, `workflow`.
- Изменение поведения блока обновляет его документацию в том же PR.
